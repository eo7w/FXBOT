# بوت إشارات الذهب XAUUSD إلى Telegram

بوت Python يراقب بيانات XAUUSD من BiQuote، ويُرسل إشارات **شراء/بيع** مع الدخول المرجعي والهدف ووقف الخسارة وسبب الإشارة، ثم يتابع السعر حتى الهدف أو الوقف أو انتهاء مدة المتابعة. **لا يفتح صفقات لدى وسيط ولا يضمن الربح أو عددًا ثابتًا من الفرص.**

## الاستراتيجية والإعدادات الافتراضية

- يحلل أطر 1 و5 و15 دقيقة؛ إشارات الدخول تبقى مبنية على الدقيقة مع سياق 5 و15 دقيقة.
- يتعرف على نماذج شائعة مثل الابتلاع، الدوجي، المطرقة/الذيل الطويل، النجم الصباحي/المسائي، الشمعة الداخلية، والشمعة الممتلئة.
- يحدد القمم والقيعان المحلية المؤكدة بعد شمعتين مغلقتين، ويبلّغ عن إغلاق السعر فوق آخر قمة أو تحت آخر قاع مؤكد، مع هيكل HH/HL وLH/LL.
- تقاطع/ترتيب EMA، RSI، اختراق أو ارتداد قصير، وقياس ATR لضبط مسافة الوقف والهدف.
- فلتر السبريد والتقلب وحداثة السعر؛ صفقة متابعة واحدة في كل مرة لتقليل التكرار.
- `/analysis` يرسل تقريرًا فنيًا عند الطلب، وتضيف الإشارات ملخص الاتجاه والقمم/القيعان ونمط الشمعة والتوصية المشروطة.
- هدف قريب نسبيًا، وحد أقصى **30 إشارة متابعة في اليوم (UTC)**. هذا سقف وليس وعدًا بإصدار 20 أو 30 إشارة؛ قد تقل الفرص إذا لم تتحقق الشروط أو كان السوق مغلقًا/السبريد واسعًا.
- الإشارات مرجعية فقط: الأسعار والتتبع افتراضيان، وقد تختلف التعبئة الفعلية بسبب السبريد والعمولة والانزلاق.

## الإعداد محليًا

1. أنشئ بوتًا في Telegram عبر BotFather، ثم ابدأ محادثة معه بزر **Start**؛ Telegram لا يسمح عادةً للبوت ببدء مراسلة مستخدم لم يبدأ المحادثة.
2. انسخ `.env.example` إلى `.env`، ثم أضف السر محليًا إلى `BOT_TOKEN` أو ضع مسار ملفه الخارجي في `BOT_TOKEN_FILE`. لا ترفع `.env` أو ملف السر إلى Git؛ `.env` مستثنى في `.gitignore`.
3. ثبّت وشغّل:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## النشر على Render

المستودع يتضمن `render.yaml` لخدمة **Web Service** واحدة تشغّل لوحة المتابعة والبوت معًا. بعد ربط المستودع بـ Render، أضف **توكنًا جديدًا** في إعدادات Environment كمتغير سري باسم `BOT_TOKEN`؛ لا تضع أي رمز في GitHub أو ملف Blueprint. إذا كان الرمز الذي سبق إرساله ما زال فعالًا، ألغِه من BotFather أولًا ثم أنشئ بديلًا. `CHAT_ID` مضبوط افتراضيًا إلى `8952278702` ويمكن تغييره من إعدادات الخدمة.

يشغّل `run_service.py` حلقة البوت مرة واحدة في عملية المشرف، ثم يشغّل Gunicorn لواجهة الويب؛ زيادة عمال Gunicorn لا تبدأ نسخًا إضافية من البوت. أبقِ عدد **نسخ Render instances = 1**؛ التوسّع إلى عدة instances منفصلة يشغّل بوتًا في كل نسخة لأن الأقفال والملفات المحلية ليست مشتركة بينها.

للاستمرار في تتبع صفقة مفتوحة بعد إعادة التشغيل أو إعادة النشر، اربط Persistent Disk على Render عند الحاجة (قد تترتب عليه رسوم إضافية)، واضبط `STATE_FILE` مثلًا إلى `/var/data/state.json` مع مسار الـ mount المطابق. دون قرص دائم قد يفقد Render ملف الحالة عند إعادة النشر، مع أن الخدمة تعيد البدء تلقائيًا.

## أوامر Telegram

- `/analysis` — تقرير الاتجاهات والقمم/القيعان والاختراقات والشموع والاقتراح المشروط.
- `/status` — حالة الخدمة والصفقة قيد المتابعة.
- `/pause` — يوقف الإشارات الجديدة فقط؛ تستمر متابعة الصفقة المفتوحة.
- `/resume` — استئناف الإشارات.
- `/help` — عرض الأوامر.

## متغيرات البيئة

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `BOT_TOKEN` | فارغ عمدًا | تضيفه بنفسك في إعدادات Render أو `.env` المحلي. |
| `BOT_TOKEN_FILE` | فارغ | مسار ملف سرّي خارجي يقرأ منه البوت الرمز عند ترك `BOT_TOKEN` فارغًا. |
| `CHAT_ID` | `8952278702` | معرّف محادثة Telegram المستلم. |
| `BIQUOTE_BASE_URL` | `https://biquote.io/api` | عنوان API العام لبيانات BiQuote. |
| `BIQUOTE_SYMBOL` | `XAUUSD` | الرمز المراد متابعته. |
| `MAX_DAILY_TRADES` | `30` | سقف الإشارات المرسلة يوميًا، لا عدد مضمون. |
| `MAX_SPREAD` | `0.50` | يتجاهل الإشارة إذا تجاوز السبريد هذا المقدار السعري. |
| `MIN_ATR` | `0.30` | حد أدنى للتقلب السعري. |
| `MAX_HOLD_MINUTES` | `20` | إغلاق المتابعة زمنيًا إن لم يُلمس الهدف أو الوقف. |
| `LOOP_SECONDS` | `5` | وتيرة فحص السعر. |
| `CANDLE_REFRESH_SECONDS` | `20` | وتيرة تحديث الشموع. |
| `STATE_FILE` | `state.json` | مكان حفظ الصفقة المفتوحة والحالة. |

## لوحة الويب

يتضمن المشروع لوحة عربية للقراءة فقط تعرض سعر XAUUSD عبر بث BiQuote SignalR اللحظي، وحالة خدمة البوت وعدد إشارات اليوم والصفقة الجاري تتبعها. السعر يتحدث عند وصول كل tick؛ أما حالة البوت فقط فتُحدّث دوريًا كل 10 ثوانٍ. لتشغيلهما محليًا معًا بعد تثبيت التبعيات، نفّذ من مجلد المشروع:

```bash
pip install -r requirements.txt
PORT=8080 python run_service.py
```

تستخدم الخدمة قيمة `PORT` التي يحددها Render تلقائيًا. يقبل `WEB_WORKERS` عدد عمال Gunicorn (الافتراضي 2)، ويمنع قفل محلي بدء أكثر من حلقة بوت على المضيف نفسه. يتصل المتصفح مباشرة بـ`https://biquote.io/hubs/tick` ويشترك في `ReceiveTick` للرمز المحدد؛ يعيد SignalR الاتصال تلقائيًا ويحاول التطبيق إعادة الاشتراك بعد رجوع الاتصال. لا يجلب `/api/status` سعر السوق، بل يقرأ حالة البوت فقط. اترك `STATE_FILE` مشتركًا بين مكونات هذه الخدمة؛ ولا تشغّل `bot.py` كخدمة مستقلة بالتوازي معها.

لا تتطلب لوحة الويب كلمة مرور، كما طلبت؛ لذا يستطيع كل من يصل إلى عنوانها مشاهدة بيانات الحالة والأسعار. الواجهة و`/api/status` للقراءة فقط ولا تنفذ أوامر تداول أو تحكم.
